Page 3 — Database Engine

3. Database Engine Upgrade: MySQL / MariaDB Dual-Engine Persistence

Prior versions stored data inside a single pos.json file. To eliminate disk-write locking contention during peak order volumes, the updated database layer (lib/db.js) introduces a high-concurrency MySQL pooling architecture.

3.1 Managed MySQL Connection Pool

const DB_HOST = process.env.DB_HOST || "localhost";
const DB_PORT = parseInt(process.env.DB_PORT || "3306", 10);
const DB_USER = process.env.DB_USER || "root";
const DB_PASSWORD = process.env.DB_PASSWORD !== undefined ? process.env.DB_PASSWORD : "";
const DB_NAME = process.env.DB_NAME || "akb-cofeemia";

pool = mysql.createPool({
  host: DB_HOST,
  port: DB_PORT,
  user: DB_USER,
  password: DB_PASSWORD,
  database: DB_NAME,
  waitForConnections: true,
  connectionLimit: 10,
  queueLimit: 0,
});

3.2 Automatic Dynamic Migration & Resilient Fallback

During server startup (db.initDb()), the system executes an automatic initialization routine:

  • Database & Table Creation: Automatically executes SQL DDL statements to verify and create tables for settings, categories, items, orders, users, and counters.
  • Legacy Data Seeding: If the MySQL database is fresh but a historical pos.json file exists, the system automatically parses and migrates all users, menu items, table states, and past billing records into MySQL.
  • Resilient Local JSON Fallback: If the connection to MySQL fails (e.g. database server restart), the system emits a warning log and seamlessly switches to local data/pos.json persistence, keeping billing online.

4. Direct ESC/POS Thermal Printing Subsystem & Binary Encoder

To provide instant, driverless printing, Coffeemia POS features an embedded JavaScript ESC/POS binary command encoder inside public/print.js.

4.1 ESC/POS Command Hexadecimal Mapping Table

Command Name ESC/POS Code Hexadecimal Bytes Operational Purpose
Initialize PrinterESC @0x1B 0x40Resets hardware print buffer and default modes.
Select Font A/BESC M n0x1B 0x4D nToggles Font A (standard) or Font B (compact).
Text AlignmentESC a n0x1B 0x61 nAligns text: 0 = Left, 1 = Center, 2 = Right.
Bold EmphasisESC E n0x1B 0x45 nEnables (1) or disables (0) bold emphasis.
Character SizeGS ! n0x1D 0x21 nMultiplies character width and height.
Feed LinesESC d n0x1B 0x64 nFeeds paper by n line spaces.
Auto Paper CutGS V m0x1D 0x56 0x42 0x00Triggers automatic guillotine paper cutter.

4.2 Encoder Implementation Excerpt

function EscPosEncoder() { this.buffer = []; }
EscPosEncoder.prototype.init = function () { this.buffer.push(0x1B, 0x40); return this; };
EscPosEncoder.prototype.align = function (pos) {
  const v = pos === "center" || pos === "c" ? 1 : pos === "right" || pos === "r" ? 2 : 0;
  this.buffer.push(0x1B, 0x61, v); return this;
};
EscPosEncoder.prototype.bold = function (enable) { this.buffer.push(0x1B, 0x45, enable !== false ? 1 : 0); return this; };
EscPosEncoder.prototype.text = function (str) {
  const clean = String(str || "").replace(/₹/g, "Rs.").replace(/·/g, "-");
  const bytes = new TextEncoder().encode(clean);
  for (let i = 0; i < bytes.length; i++) this.buffer.push(bytes[i]);
  return this;
};
EscPosEncoder.prototype.cut = function () { this.buffer.push(0x1D, 0x56, 0x42, 0x00); return this; };

Page 11 — Operational Guides

11. Operational Guides for Cashiers & Administrators

11.1 Cashier Billing Workflow

  1. Select active Table or Takeaway Mode on the main dashboard.
  2. Tap menu items from the left category selector to build the order cart.
  3. Click Send KOT to fire kitchen tickets directly to thermal printers.
  4. Upon customer payment, select Cash / UPI / Card and click Settle Bill.
  5. The system automatically prints the final customer receipt and triggers paper cut.

11.2 Admin Printer Setup Instructions

  1. Wi-Fi Printer: Print self-test sheet to find IP. Enter IP & Port 9100 in Settings > Hardware Settings. Click Save & Test Print.
  2. Bluetooth Printer: Turn on printer. Select Web Bluetooth in Settings and click Pair Bluetooth Device.

12.1 System Diagnostic Matrix

Symptom Possible Cause Recommended Action
Network Print 504 Error Printer IP changed / offline Verify IP via self-test sheet; ensure printer and POS terminal share subnet.

Bluetooth Fail Non-HTTPS or BLE off Web Bluetooth requires HTTPS or localhost. Enable BLE flags in browser.
DB Connection Error MySQL service offline Check MySQL status. Application automatically runs on local JSON backup until DB recovers.
